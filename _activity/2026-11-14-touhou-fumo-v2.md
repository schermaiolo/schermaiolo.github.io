**Touhou Fumo Companion v2.0.0** is a big update without a new character. Instead, the existing Fumos learned to fly. (And fall. And bounce.)

- **VS Code:** Grab a Fumo from the Explorer or Bottom Panel and throw her. The optional **Bounce inside the code editor** setting lets her travel through the editor area before returning home.
- **Pragtical:** Drag and flick a Fumo across the window, with gravity, wall/floor bounces, and a return-home animation. Grab & Throw is enabled by default on new installations.
- **VS Code settings:** A dedicated, friendlier interface now groups **Basics**, **Fumos**, **Movement**, **Reaction Rules**, and **Advanced**, with a preview for each selected Fumo.
